1. 引言

本规范定义了一套机制， 用于根据指针位置在指定范围内的进度 驱动动画进度。 这类 指针驱动动画 使用基于指针位置的时间线， 以长度而非时间为基准。 因此它们在运作方式及概念上 类似于 滚动驱动动画。 本模块既提供基于 Web Animations API的命令式API，也提供基于 CSS Animations的声明式API。 [CSS-ANIMATIONS-2] [WEB-ANIMATIONS-1]

1.1. 与其他规范的关系

Web Animations [WEB-ANIMATIONS-1] 为Web平台上的动画 定义了一个抽象的概念模型； 模型的组成部分包括 动画 及其 时间线， 以及相关的编程接口。 本规范扩展了Web Animations模型： 它定义了 指针进度时间线 ，允许这些时间线驱动 动画 的进度，从而创建 指针驱动动画。

本规范既引入了 用于操作这些概念的编程接口， 也引入了将这些概念应用于 CSS动画的CSS属性 [CSS-ANIMATIONS-1]。 如果这些CSS属性的行为可以通过编程接口来描述， 那么， 用户代理 即使不支持脚本， 也仍可符合本规范， 方法是实现相应CSS功能，使其表现得 就像底层编程接口已实现一样。

本规范源自滚动驱动动画模块 [SCROLL-ANIMATIONS-1] 中为指定基于进度的时间线和动画 而引入的概念和功能，并受其启发。

与CSS中除 选择器 匹配以外的大多数操作一样， 本规范的功能也在 扁平化元素树。

1.2. 值定义

本规范遵循 CSS属性定义约定 （见 [CSS2] ），并采用 值定义语法 （见 [CSS-VALUES-3]）。 本规范未定义的值类型 在CSS值与单位中定义 [CSS-VALUES-3]。 与其他CSS模块结合时，这些值类型的定义可能会扩展。

除各属性定义中列出的特有值之外， 本规范定义的所有属性 也接受 CSS全局关键字 作为属性值。 为了易读，这里不逐个重复列出。

2. 指针进度时间线

指针进度时间线 是与指针位置在元素的 主盒 上沿特定轴移动的进度相关联的时间线。

指针范围 是 元素 主盒 沿 指针进度时间线的轴方向上的尺寸。

指针偏移 是指针相对于 元素的 指针范围 起点的位置，由 offsetX 和 offsetY 定义，见 [CSSOM-VIEW-1]。 最靠近起点的 指针偏移 表示进度为0%， 最靠近终点的 指针偏移 表示进度为100%。

指针进度时间线 可以在 animation-timeline 中通过 pointer() 函数表示法 匿名引用，也可以按名称引用（见 滚动驱动动画 § 4.2 具名时间线的作用域与查找） ，前提是已使用 pointer-timeline 属性声明这些时间线。 在Web Animations API中， 可以使用 PointerTimeline 对象来匿名表示它们。

2.1. 指针进度时间线的范围

指针进度时间线 定义了以下 具名时间线范围：

fill
表示 指针进度时间线的完整范围：

  • 进度0%表示指针位于元素的 起始侧 内边距边缘 ，所属盒为 主盒。

  • 进度100%表示指针位于元素的 结束侧 内边距边缘 ，所属盒为 主盒。

fit
表示一个与 fill, 等大的范围，但0%和100%进度点根据 animation-range-center 属性的值偏移，使50%进度点 仍位于范围中心。
cover
表示 指针进度时间线 能完全覆盖元素 主盒 的最大可能范围，根据 animation-range-center 属性的值确定，具体如下：

  • 如果50%进度点到元素 起始侧 内边距边缘 的距离大于 50%进度点到元素 结束侧 内边距边缘的距离， 则0%进度点位于元素的 起始侧 内边距边缘， 而100%进度点位于50%进度点的另一侧， 两者到50%进度点的距离相同。

  • 否则，100%进度点位于元素的 结束侧 内边距边缘，而0%进度点在另一侧， 到50%进度点的距离相同。

contain
表示完全位于元素 主盒 内的最大可能范围，根据 animation-range-center 属性的值按如下方式确定：

  • 如果50%进度点到元素 起始侧 内边距边缘 的距离小于 50%进度点到元素 结束侧 内边距边缘的距离， 则0%进度点位于元素的 起始侧 内边距边缘， 而100%进度点位于50%进度点的另一侧， 两者到50%进度点的距离相同。

  • 否则，100%进度点位于元素的 结束侧 内边距边缘，而0%进度点在另一侧， 到50%进度点的距离相同。

插入示意图。

在所有情况下，用来确定 书写模式 所对应的 起始侧 和 结束侧 时， 所用的 书写模式 均取自相关的 主盒为准。 变换 会被忽略， 但会考虑 相对 定位与 绝对 定位 。

2.2. 计算指针进度时间线的进度

进度（即 当前时间）对于 指针进度时间线 按下式计算： 指针偏移 ÷ 指针范围

如果0%位置与100%位置重合 （即 当前时间 公式的分母为零）， 则时间线 不活动。

2.3. 匿名指针进度时间线

2.3.1. pointer() 表示法

pointer() 函数表示法 可用作 <single-animation-timeline> 值，适用属性为 animation-timeline ，其指定一条 指针进度时间线。 语法如下：

<pointer()> = pointer( [ <source> || <axis> ]? )
<axis> = block | inline | x | y
<source> = root | nearest | self

默认情况下， pointer() 引用 行内轴 ，其所属范围为元素自身的 指针范围。 参数按如下方式改变此查找：

block
指定沿以下轴度量进度： 块轴 （对应于 指针范围）.
inline
指定沿以下轴度量进度： 行内轴 （对应于 指针范围）. （默认值。）
x
指定沿以下轴度量进度： 水平轴 （对应于 指针范围）.
y
指定沿以下轴度量进度： 垂直轴 （对应于 指针范围）.
self
指定使用元素自身的 主盒 作为 指针范围. （默认值。）
nearest
指定使用最近元素的 父盒 作为 指针范围.
root
指定使用根元素的 主盒 作为 指针范围.

每次使用 pointer() 都对应一个独立的 PointerTimeline 实例（在Web Animations API中）， 即使多个元素以相同的参数使用 pointer() 引用 同一个 指针范围 也是如此。

2.3.2. PointerTimeline 接口

enum PointerAxis {
  "block",
  "inline",
  "x",
  "y"
};

dictionary PointerTimelineOptions {
  Element? source;
  PointerAxis axis = "block";
};

[Exposed=Window]
interface PointerTimeline : AnimationTimeline {
  constructor(optional PointerTimelineOptions options = {});
  readonly attribute Element? source;
  readonly attribute PointerAxis axis;
};

PointerTimeline 是一个 AnimationTimeline ，表示一条 指针进度时间线。 它可以传递给 Animation 构造器或 animate() 方法， 从而将动画关联到 指针进度时间线。

source, ，类型为 Element，只读，可空

其 指针偏移 驱动 时间线进度的元素。

axis, ，类型为 PointerAxis，只读

驱动时间线进度的轴。 参见上文 <axis>的值定义。

继承的属性：

currentTime （继承自 AnimationTimeline）

表示 指针范围 内的指针进度，表示为百分比CSSUnitValue； 0%表示最靠近起点的 指针偏移。 时间线 不活动时为null。

PointerTimeline(options)

按以下步骤创建一个新的 PointerTimeline 对象：

  1. 令 timeline 为新建的 PointerTimeline 对象。

  2. 设置 source （属于 timeline ），取值如下：

    如果 source 成员存在于 options 中，

    source 成员，取自 options。

    否则，

    根元素。

  3. 将 axis 属性（属于 timeline ）设为 options中相应的值。

如果 source （属于 PointerTimeline ）是一个 主盒 不存在的元素， 则 PointerTimeline 为 不活动。

source 和 currentTime 的值在任一值被请求或更新时一并计算。

2.4. 具名指针进度时间线

指针进度时间线 也可以通过声明定义， 然后在该名称的作用域内 由元素按名称引用 （见 滚动驱动动画 § 4.2 具名时间线的作用域与查找）。

此类 具名指针进度时间线 在 协调值列表 中声明；该列表由 pointer-timeline-* 属性构成， 这些属性组成一个 协调列表属性组 ，以 pointer-timeline-name 为 协调列表基准属性。 见 CSS值4 § A 协调列表值属性。

2.4.1. 为指针进度时间线命名： pointer-timeline-name 属性

名称： pointer-timeline-name
值： [ none | <dashed-ident> ]#
初始值： none
适用范围： 所有元素
继承： 否
百分比： 不适用
计算值： 关键字 none 或一个以下内容的列表： CSS标识符
规范顺序： 按语法
动画类型： 不可动画化

指定此元素所关联的 具名指针进度时间线 的名称。

2.4.2. 指针进度时间线的轴： pointer-timeline-axis 属性

名称： pointer-timeline-axis
值： [ block | inline | x | y ]#
初始值： block
适用范围： 所有元素
继承： 否
百分比： 不适用
计算值： 指定关键字的列表
规范顺序： 按语法
动画类型： 不可动画化

指定 具名指针进度时间线 的轴；这些时间线由此元素的 主盒派生。 如果此元素的 主盒 不存在， 则对应的 具名指针进度时间线 是 不活动的。

值的定义见 pointer()。

2.4.3. 指针时间线的简写： pointer-timeline 简写属性

名称： pointer-timeline
值： [ <'pointer-timeline-name'> <'pointer-timeline-axis'>? ]#
初始值： 见各个属性
适用范围： 所有元素
继承： 见各个属性
百分比： 见各个属性
计算值： 见各个属性
动画类型： 见各个属性
规范顺序： 按语法

此属性是一个 简写属性 ，用于设置 pointer-timeline-name 和 pointer-timeline-axis ，只需一条声明。

附录A：动画范围居中

本节应移至CSS-ANIMATIONS-2和WEB-ANIMATIONS-2。

滚动驱动动画 § 将动画附着到时间线范围 一节引入了将一组动画关键帧 附着到 动画附着范围的概念，从而为动画 创建一个线性的进度范围。

指针驱动动画新增了一项能力： 可将动画的焦点（50%进度点） 设为指定的位置，而不必使用 默认的 动画附着范围中心。这可以 用 animation-range-center 属性实现。

动画范围中心主体 是一个元素，其 主盒 就是计算 活动范围中心时用作参照的范围。该主体由 <timeline-range-center-subject> 值类型表示， 它是一个 CSS标识符 ，表示 下列值之一：

source
其 指针偏移 驱动时间线进度的元素。
target
应用动画的元素。

50%进度点可以小于0%进度点， 也可以大于100%进度点。在这两种情况下， 动画附着范围 在50%进度点截断。

指定动画时间线范围的中心： animation-range-center 属性

名称： animation-range-center
值： [ normal | [ <length-percentage> | <timeline-range-center-subject> <length-percentage>? ] ]#
初始值： normal
适用范围： 所有元素
继承： 否
百分比： 相对于指定时间线范围中心主体的对应尺寸；否则 相对于 动画附着范围的起点
计算值： 一个列表，每一项都是关键字 normal ，或一个时间线范围中心主体与一个长度百分比值
规范顺序： 按语法
动画类型： 不可动画化

指定 动画附着范围的中心点， 即动画范围内50%进度点的位置。

各值含义如下：

normal
动画 活动区间 的50%进度点位于 动画附着范围的中心.
<length-percentage>
动画 活动区间 的50%进度点位于 时间线 上的指定点，从 动画附着范围的起点计量. 百分比相对于 动画附着范围的大小.
<timeline-range-name> <length-percentage>?
动画 活动区间 的50%进度点位于相对于 起始侧 内边距边缘 的指定点， 该边缘来自指定 动画范围中心主体的 主盒. 若 <length-percentage> 省略， 则默认为50%。

    如果样式表中使用本模块所定义语法的所有语句， 都符合CSS通用语法及本模块所定义的 各项功能的具体语法， 则该样式表符合本规范。

    如果渲染器除按适用规范解释样式表外， 还通过正确解析本规范定义的所有功能 并相应渲染文档来支持它们， 则该渲染器符合本规范。 不过，如果用户代理因设备限制 而无法正确渲染文档， 并不意味着它不符合规范。（例如，不要求 用户代理在单色显示器上呈现颜色。）

    如果编写工具生成的样式表 在语法上符合CSS通用语法和本模块 定义的各项功能的具体语法， 并满足本模块对样式表规定的 所有其他一致性要求，则该工具符合本规范。

    部分实现

    为了让作者利用前向兼容的解析规则 指定后备值，CSS渲染器 必须 将不受支持的语法视为无效（并 忽略 ，视情况而定），包括无法提供可用支持的任何at规则、属性、属性值、关键字 及其他语法结构。 特别是，用户代理 不得 有选择地 忽略单个多值属性声明中不受支持的分量值，同时保留受支持的值： 如果其中任何值被视为无效 （不受支持的值必须视为无效），CSS就要求 忽略整条声明。

    不稳定功能及专有功能的实现

    为避免与未来稳定的CSS功能冲突， CSS工作组建议 遵循最佳实践 来实现CSS中的 不稳定 功能和 专有扩展 。

    非实验性实现

    一旦规范达到候选推荐标准阶段， 就可以提供非实验性实现；实现者应当 发布不带前缀的候选推荐标准功能实现， 前提是能够证明其实现正确且符合规范。

    为建立并保持CSS在不同实现间的互操作性， CSS工作组要求非实验性的 CSS渲染器，在发布任何不带前缀的CSS功能实现之前， 向W3C提交实现报告（以及必要时 提交该报告使用的测试用例）。 提交给W3C的测试用例须由CSS工作组 审查和修正。

    有关提交测试用例和实现报告的更多信息， 可在CSS工作组的网站上找到： https://www.w3.org/Style/CSS/Test/. 如有疑问，请发送至 public-css-testsuite@w3.org mailing list.
